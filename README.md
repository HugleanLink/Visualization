这是一个基于streamlit平台开发的metar分析工具，旨在将复杂的文本数据转化为可视化图表
目前支持气温、露点、风速、风向四种指标的分析并生成热图或风玫瑰图，可以选择时区（utc+0和utc+8两种）和年份范围（单年份数据和指定区间的多年份数据）
值得两提的是，
    1.处理风向时，不能直接取算术平均值。例如350°和10°的算数平均是180°（南风），而它们应该都是北风。正确做法是将角度转换为单位向量的东西分量U和南北分量V，其中U=sinθ；V=cosθ，平均风向为arctan2（ΣU，ΣV）
    2.处理时区时，如果选择utc+0,正常计算和处理，因为metar报文里的格式就是utc+0.如果选择北京时间，我的处理方式是在数据清洗模块给出的数据里加8小时，而不是将坐标轴移动8小时，这样做的好处是如果是utc+0的3月31日22：00的数据，选择北京时间，前者会变成4月1日6：00，算作四月份的数据，参与四月的坐标轴的计算，而后者还是参与三月坐标轴的计算，导致误差变大
